# 配置教程
## 准备工作
首先，准备一台实体机/虚拟机，确保这台机器等于或大于以下配置：
- 处理器：一核以上
- 内存：512MB以上
- 硬盘：512MB以上
- 一个键盘
- 一个蜂鸣器或音频输出设备
- 建议装上AMD驱动的网卡（Intel驱动的网卡似乎无法运行）

## 安装CMLeonOS
将CMLeonOS的ISO文件挂载到虚拟机或实体机上，启动后按照提示进行 First time setup（如果没有格式化硬盘则会进入Format Disk页面，格式化成功后会进入First time setup）。

在 First time setup 中，系统会让你配置用户名、密码、主机名，配置完后会进行重启，重启之后正常登陆系统，然后就可以开始使用CMLeonOS了。
